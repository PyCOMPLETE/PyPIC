# CPU examples

Install the package and plotting dependencies from the repository root:

```sh
python -m pip install -e '.[examples]'
python examples/cpu/000_test_round_chamber.py
```

The examples use the installed `PyPIC` package. Run them as scripts; they execute
their simulations at the top level. Plots open interactively by default. For a
headless run, set `MPLBACKEND=Agg`. Generated plots and `.mat` files go into the
current working directory. Random particle examples use a fixed seed.

| Script | Demonstrates |
| --- | --- |
| `000_test_round_chamber.py` | Staircase, Shortley-Weller, open-boundary FFT, and dual-grid fields |
| `002_test_rect_chamber.py` | Finite differences and FFT in a rectangular conducting chamber |
| `003_Xmas_tree.py` | Fields from a tree-shaped particle distribution; saves PNG plots |
| `004_test_gaussian.py` | Open-boundary FFT compared with the analytic round-Gaussian field |
| `005_testfftw.py` | NumPy versus pyFFTW timing, with a numerical agreement check |
| `006_time_solve.py` | Poisson-solver timing |
| `007_test_separately.py` | Step-by-step FFT solve, checked against the solver's result |
| `008a_check_interpolation_near_borders.py` | Generates Shortley-Weller, staircase, and Bassetti-Erskine boundary datasets |
| `008b_check_interpolation_near_borders_plots.py` | Plots the three datasets generated by `008a` |
| `009_test_round_chamber_for_new_interp_devel.py` | Shortley-Weller interpolation in a round chamber |
| `010_effect_of_tolerances_in_SW.py` | Shortley-Weller field accuracy near the wall |
| `011_LHC_multigrid_test.py` | LHC bunch: single-grid and telescopic-grid fields against Bassetti-Erskine |
| `012_test_states.py` | Multiple charge states sharing the same solver |

Ordinary examples use NumPy FFT and SciPy's sparse solver. The `005` benchmark
additionally requires `pyfftw` (`python -m pip install -e '.[examples,fftw]'`).
The `011` example and its `LHC.py` helper additionally require `PyHEADTAIL`.

The timing examples (`005`, `006`, and `011`) accept `--repetitions`:

```sh
python examples/cpu/006_time_solve.py --repetitions 3
```

Run the boundary pair in order from the same working directory:

```sh
python examples/cpu/008a_check_interpolation_near_borders.py
python examples/cpu/008b_check_interpolation_near_borders_plots.py
```

The default grid spacing is 0.5 mm in both scripts. If changing it, keep both
scripts consistent and regenerate all three datasets. Fine-grid studies (`000`,
`010`, and `011`) can take longer and use more memory than the other examples.
